# nfdsmodelling

The goal of nfdsmodelling is currently to make a nfds model for the SA
dataset. The package provides the necessary functions to accomplish this
and can be reused for later projects.

## Installation

You can install the development version of nfdsmodelling from
[GitHub](https://github.com/) with:

``` r

# install.packages("pak")
pak::pak("MAGPIE-SFU/newmo@workflow")
```

## Example

This is a basic example which shows you how to solve a common problem:

``` r

library(nfdsmodelling)
## basic example code
```
