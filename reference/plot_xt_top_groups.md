# Plot the most common groups in x(t) with uncertainty

Plot the most common groups in x(t) with uncertainty

## Usage

``` r
plot_xt_top_groups(xt_agg, n_top = 20)
```

## Arguments

- xt_agg:

  x(t) from
  [`reweight_carriage_uncertainty()`](reweight_carriage_uncertainty.md).

- n_top:

  Number of most common groups to show.

## Value

A ggplot.
