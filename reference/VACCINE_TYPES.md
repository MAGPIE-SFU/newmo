# Serotypes covered by each pneumococcal vaccine

A named list of character vectors, one per vaccine. Labels must match
the serotype labels used in the model data (check "15B"/"15C" and
"20"/"20A"). Renamed 15B in PCV21 and PCV23 to 15B/C due to other parts
of our model

## Usage

``` r
VACCINE_TYPES
```
